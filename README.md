# 🏦 Reto: Analista de Portafolio

**Lenguajes de Programación · Ingeniería Financiera**

---

## 📋 Descripción

Programa en Python para analizar un portafolio de inversión compuesto por 4 activos (acciones). El programa calcula automáticamente los indicadores financieros clave y genera recomendaciones de inversión basadas en reglas predefinidas.

## 🛠️ Conceptos de Programación Utilizados

- **Variables:** Almacenamiento de datos numéricos y textos
- **Diccionarios:** Estructura de datos para organizar información de cada activo
- **Listas:** Almacenamiento de múltiples resultados
- **Ciclos `for`:** Iteración automática sobre los activos
- **Condicionales (`if/elif/else`):** Lógica de decisión para recomendaciones
- **Funciones:** Reutilización de código para cálculos
- **Lambda functions:** Identificación del mejor activo

## 💡 Conclusión

El análisis del portafolio revela un rendimiento total positivo de **2.91%**, impulsado principalmente por el excelente desempeño de **JPM** con un rendimiento del **28.88%**.

Las demás acciones (AMZN, NVDA y ADBE) presentan pérdidas que sugieren analizar una posible venta según las reglas de decisión establecidas.

Este ejercicio demuestra cómo la programación en Python puede automatizar análisis financieros, procesar múltiples activos simultáneamente y generar información valiosa para la toma de decisiones de inversión.
